# One-Line Slogan for a Solana Wallet Agent

Entry for the make.fun bounty
`u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e`.

`main.py` writes a single one-line slogan (16 words, 84 characters) to
`/output/entry.txt`:

> Your Solana wallet agent reads the fine print so your SOL never learns the hard way.

Run: `python3 main.py`. Deterministic, no network, standard library only.
